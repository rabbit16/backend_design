# 设计系统

## 风格定位

- 平台：Android 手机 App
- 用户：老年用户
- 风格：简单、清晰、温和、高对比
- 颜色：暖白背景 + 深蓝主操作 + 红色录音状态 + 绿色结果状态

## 设计 Token 文件

代码中的设计令牌集中在：

```text
src/theme/tokens.ts
```

修改颜色、间距、字号时，优先修改该文件，不要在页面中随意写新的颜色。

## 色彩

| Token | 用途 | 当前值 |
|---|---|---|
| `backgroundWarm` | 页面背景 | `#FFF9EE` |
| `surface` | 卡片/按钮文字 | `#FFFFFF` |
| `primary` | 主要操作按钮 | `#175EA8` |
| `primarySoft` | 主按钮外圈 | `#D7E9FB` |
| `textPrimary` | 主标题/正文 | `#172033` |
| `textSecondary` | 次级说明 | `#4B5563` |
| `danger` | 录音中状态 | `#B8322C` |
| `success` | 结果标题 | `#285B28` |

## 字体规范

| 用途 | 字号 | 行高 | 字重 |
|---|---:|---:|---:|
| 首页标题 | 28 | 36 | 700 |
| 卡片标题 | 23 | 32 | 700 |
| 正文大字 | 18 | 28 | 400 |
| 状态文本 | 20 | 30 | 600 |
| 主按钮文字 | 21 | 28 | 700 |

## 触控规范

- 普通按钮最小触控区域：48dp
- 核心语音按钮：176dp
- 语言切换按钮：不低于 44dp 高
- 按压反馈：透明度变化，不改变布局尺寸

## 页面结构

首页由以下区域组成：

1. 顶部标题区：欢迎语、产品名、语言切换
2. 说明卡片：告诉用户如何使用
3. 语音按钮区：按住说话，松开结束
4. 状态区：录音中/处理中/等待输入
5. 结果区：展示返回结果

## 无障碍要求

- 所有可点击控件必须使用 `Pressable` 或类似语义控件。
- 图标不能只靠颜色表达状态；需要配合文字。
- 使用 `accessibilityLabel` 和 `accessibilityHint`。
- 使用 `accessibilityLiveRegion` 提醒状态变化。
- 不使用 emoji 作为结构性图标；当前麦克风图形由 View 绘制。
